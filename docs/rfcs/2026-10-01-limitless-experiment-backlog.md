# Experiment backlog: historical “Limitless” ideas as recipes

Status: Backlog  
Blocked by: P0; some recipes also require P2 external outcomes

The historical ideas should become **experiment recipes over existing NOOP primitives**, not new branded
subsystems.

## Initial recipe families

### Wind-down
Breathing / meditation / NSDR / screen timing / meal timing → pre-sleep HR → sleep → next-morning HRV/RHR.

### Caffeine timing
User-entered timing/exposure → sleep + next-day readiness.

### Training timing / load
Workout type/time/load → sleep/recovery/next-day state.

### Heat / cold
User-entered exposure → HRV/RHR/sleep/recovery.

### Breathwork
Existing Breathe session → pre/post HRV + next-night/day outcomes.

### Sleep regularity
Timing consistency → readiness / Healthspan-related outcomes.

### Flow
Subjective flow/focus → physiological context + external work outcome.

### Learning-state matching
Learning session under different sleep/readiness states → 24h / 7d retrieval and transfer.

### AI augmentation
Assisted vs unassisted work → immediate task quality + delayed unassisted performance.

### Supplements / medications / compounds
Record user-entered exposure only. No recommendation or treatment logic.

## Recipe requirements

Every promoted recipe must specify:
- existing Journal factor key where available
- baseline
- exposure window
- primary outcome
- lag/outcome window
- coverage/sample gate
- falsification rule
- duplicate check against current NOOP features/issues

## Explicitly rejected

- Limitless / NZT score
- biological-optimization score
- separate protocol database
- autonomous supplement/treatment recommender
